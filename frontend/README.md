# Leyde Frontend (Next.js 15)

Estrutura base do frontend usando Next.js 15 (App Router), TypeScript e Tailwind CSS.

Objetivo: apenas estruturar pastas e arquivos de configuração; nenhuma tela foi implementada.

Principais passos para iniciar (opcional):

1. Instalar dependências: `npm install`
2. Rodar em desenvolvimento: `npm run dev`

Nota: antes de implementar telas, leia PROJECT.md e Skills do projeto e siga o Design System.
