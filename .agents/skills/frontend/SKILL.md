# Frontend

This project frontend must be developed using:

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

## Architecture

- Never access the database directly.
- Always consume the Java REST API.
- Keep components reusable.
- Use server components whenever appropriate.
- Use client components only when necessary.
- Follow the Apple Design System.
- Follow the Ecommerce business rules.

## Pages

- Home
- Products
- Product Details
- Brands
- Categories
- Promotions
- Search
- Login (Admin)
- Dashboard (Admin)

## Components

- Navbar
- Hero Banner
- Product Card
- Product Grid
- Search
- Filters
- Footer
- WhatsApp Button
- Breadcrumb
- Pagination

Always create responsive pages.

Never duplicate components.

Use clean folder organization.
