# Apple Design System

Whenever you create an interface for this project:

1. First read:

docs/design-system/apple/USAGE.md

2. Then read:

docs/design-system/apple/DESIGN.md

3. Use the tokens from:

docs/design-system/apple/tokens.css

4. Refer to:

docs/design-system/apple/components.manifest.json

5. If you need the HTML structure of the components:

docs/design-system/apple/components.html

Never invent components that do not exist.

Never use colors outside the tokens.

Never change the typography.

Always follow the Apple Design System exactly.
