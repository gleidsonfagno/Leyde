# Java Skill

Esta skill deve ser utilizada sempre que a tarefa envolver desenvolvimento em Java.

## Regras

- Utilizar Java 21.
- Seguir Clean Code.
- Utilizar orientação a objetos.
- Utilizar records quando fizer sentido.
- Evitar código duplicado.
- Criar classes pequenas e com responsabilidade única.
- Utilizar Optional quando apropriado.
- Escrever código legível e bem organizado.

## Convenções

- Classes em PascalCase.
- Métodos em camelCase.
- Constantes em UPPER_SNAKE_CASE.
- Pacotes em letras minúsculas.

## Prioridades

- Legibilidade.
- Manutenibilidade.
- Performance quando necessário.
- Segurança.

## Evitar

- Código duplicado.
- Métodos muito grandes.
- Classes gigantes.
- Lógica espalhada pela aplicação.
